# Agent Note: 缓存感知的压力修剪

Status: implemented

[English](2026-10-19-cache-aware-pressure-pruning.md) | 中文

## 问题

替换一个工具结果会从该结果起改写模型请求，因此提供方的前缀缓存必须重新预填充整个后缀。`dsh-compaction-basic` 曾在压力条件一满足、尚未决定是否摘要之前，就修剪所有超出预算的工具结果。因此一次较早位置的替换几乎会重新预填充整个窗口；修剪之后再摘要，还会让摘要请求脱离已缓存的对话前缀。

一个由本地 vLLM 后端服务的已记录编码 Session 测得了这一代价。普通步骤约有 99% 命中前缀缓存，预填充速度为 770–860 token/s。三次压力修剪分别重新预填充了 201,372、9,590 与 196,946 个 token，首 token 等待分别为 246.6 s、14.4 s 与 256.3 s。它们分别只释放了约 76K、5K 与 3.5K 个 token，而且每次之后分别在 51、3 与 5.5 分钟后仍发生了完整压缩。

## 决策

压力触发时，`compaction-basic` 通过 `ToolResultPruner.estimateSession()` 获取待落地的替换。只有满足下列条件之一时，它才会在摘要之前修剪：

- 这些替换释放的启发式 token 数，至少是从最早替换处开始、按修剪后定价的请求后缀的 `pressurePruneMinGainRatio` 倍。
- 没有可摘要的范围，因此修剪是唯一可用的缓解手段。

否则摘要读取未改动且已缓存的前缀。每次压力摘要之后，引擎会修剪替换后的 surface。每个压缩范围都从第一个非系统节点开始，因此剩余的每个工具结果都位于新摘要之后，修剪它们只改变下一个请求本来就要重新预填充的 token。

`pressurePruneMinGainRatio` 是支持按模型覆盖的策略字段，默认值为 `1`。在已记录的 Session 中，一次压缩以约 96K 个重新预填充的 token 加上 80–135 s 的摘要解码，换来约 200K token 的余量，大约每个重新预填充 token 等价物换来一个 token 的余量。低于该比例的修剪，每释放一个 token 消耗的缓存多于它所推迟的那次压缩。取值 `0` 恢复无条件的摘要前修剪。溢出恢复总是先修剪，因为它必须在重试之前腾出空间。

## 回放

一次本地回放把已记录的事件送入新的 Session，并在每个已记录步骤之前调用 `compactIfNeeded('pressure')`。它把提供方缓存建模为相邻请求之间 surface 节点的最长公共前缀。在 138 个步骤上，启发式 meter 给出的请求价格是路由器真实 prompt token 的 0.885 倍，因此回放按该系数缩放了上下文窗口。在先前行为（`0`）下，回放复现了前两次已记录的修剪，时间误差在 2 分钟内，重新预填充误差在 1% 以内；第三次比记录晚 9 分钟，并与其压缩在同一次处理中落地。总量以真实 token 等价物计：

| 策略 | 摘要前修剪 | 压缩 | 重新预填充 token |
|---|---|---|---|
| `pressurePruneMinGainRatio: 0` | 3 | 2 | 477,018 |
| `0.25` | 2 | 2 | 328,838 |
| `0.5`、`1`、`2` | 0 | 2 | 118,134 |

取值 `1` 时，摘要请求完全复用了已缓存的前缀；剩余的重新预填充是每种策略都要付出的压缩后尾部。按测得的速度，358,884 个 token 的差额约等于七分钟的预填充。

## 考虑过的替代方案

- **在每个工具结果到达时修剪。** 这能保持缓存完好，但在已记录的 Session 中，它会在请求这些结果的那一步隐藏 1,135,405 个工具结果字符中的 303,213 个（27%），其中包括九次文件读取。
- **以窗口比例表示的收益下限**，例如 10%。它忽略替换所在的位置。已记录的最大一次修剪释放了约 92K 个估算 token，能通过该下限，却重新预填充了 201K 个 token，与一次压缩相当，换来的余量却更少。
- **低于阈值的迟滞。** 在触发点上它等同于收益下限，也有同样的弱点。

## 影响

- 压力在第一个满足条件的步骤就压缩，而不是先修剪较早的结果。回放中压缩次数仍为两次，但每次摘要来得更早，覆盖的历史跨度更短。
- 摘要从已缓存的前缀读取未修剪的工具结果。保留的尾部照旧被修剪。
- 该比例比较的是启发式 token 估算，而非提供方 token。图片定价与分词密度可能改变处于边界的决定。
- `packages/compaction/compaction-basic/tests/compaction-basic.spec.ts` 中的测试覆盖比例边界、无可摘要内容时的回退，以及用 `prefixCacheMiss` 建模的摘要请求前缀复用。
